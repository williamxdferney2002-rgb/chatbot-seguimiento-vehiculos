# Offline fixtures

`fuel-history.csv` contains 19 entirely invented rows, not operational history. Distances, prices and events are illustrative. The fixture covers two vehicles, independent efficiency calculations (11.1, 16.9, 26.5 and 13.3 km/gallon), monthly medians, price outliers, event exclusion, seven-day exclusion, period filters and bot/history deduplication. It replaces a missing private historical CSV dependency; it is not a migration file.
